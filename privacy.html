Privacy policy

Last updated: November 24, 2026

Homelab Frame Art is a personal, single-user tool. Its only user is the owner of the server it runs on.

What it accesses

  • It uploads public-domain artwork images to the user's Google Photos library and adds them to an album that the tool itself created.
  • It can only list, add to and remove from photos and albums that the tool itself created. It cannot see or change any other photos in the account.

What it does with data

  • Access credentials and logs are stored only on the owner's own server.
  • No data is sold, shared with third parties, or used for advertising.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time in your Google Account under Security, Third-party connections.

Contact

Questions can be raised on this project's GitHub Issues page.
